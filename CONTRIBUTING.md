# Contribution policy

This repository is published as a read-only record of the experiment supporting
the accompanying blog post. It is not an open collaboration project.

External issues, pull requests, code contributions, data submissions, and other
content contributions are not accepted. Unsolicited pull requests will be closed
without review.

GitHub does not provide a switch that prevents pull requests from forks of a
public repository. This policy describes how any such requests will be handled.
